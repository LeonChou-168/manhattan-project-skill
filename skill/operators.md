# 算子出处（曼哈顿工程档案证据）

主要来源：Hewlett & Anderson, *The New World 1939–1946*（美国原子能委员会官方史，B 级，
带脚注可回查原始档案）。完整证据卡片库在开发者本地 `~/Desktop/mega-project-corpus/`。

| 算子 | 史实锚点 | 关键原文/事实 |
|---|---|---|
| 双路径下注 | 1942-05-23 S-1 会议（第3章） | 五条路线全部推进到中试，各附预算与时限；同时被要求列出资源受限时的砍线顺序 |
| 不确定度→并行宽度 | 1942-10-05 Groves 芝加哥之问 | 裂变材料需求估计"correct within a factor of ten"，摧毁单线规划的可能性 |
| 授权成文 | 1942-09-17 Groves 任命令（第3章） | 前任"有责无权"失灵后换人，命令一句话："take complete charge of the entire DSM project" |
| 拍板层收窄 | 1942-06-19 S-1 执行委员会 | 全体大会停开，收窄为"每线一名可拍板者"；技术前景判断与工程执行分属两机构 |
| 招募三动作 | 1943 春夏洛斯阿拉莫斯（第7章） | 编制镜像问题结构；Serber 讲座统一底课；Lewis 外部评审一个月内推翻"小实验室"设想并扩编 |
| 围栏内开放/线间隔离 | Breit 信与 colloquium 之争（第7章） | 隔离边界画在站点之间不画在人之间；Groves 明言隔离兼防顶尖人才"frittering from one thing to another" |
| 接口协议 | 1943-06-17 Groves 交换规则（第7章） | 四条款：目的检验、禁传清单、指定通道、修订机制；实地考察走特批 |
| 行政卸载 | Lewis 委员会处方（第7章） | Oppenheimer 被行政琐事淹没→设专职行政办公室，六个月内用窄职助理顶住 |
| 杀线 | 1944-07 Pu-240 危机（第7章） | Segrè 可复现测量→"The neutron background of 240 ruled it out"→一周内遣散协调层→全所改组转内爆 |
| 补线 | 1944-04 热扩散翻案（第5章 "The Last Card"） | 1943 年按"替代 K-25"否决；目标改为"拼配额"后重审，90 天建成 S-50 |
| 先并行后串联 | 1943-05-05 军事政策委员会（第5章） | K-25 低浓缩料喂 Y-12，最终 S-50→K-25→Y-12 三级流水线；中间产物 = 单一标量（浓缩度） |
| 探索线收缩不清零 | super 的处置（第7章） | 小组规模、"不干扰主线"为硬约束；1944-02 判明本期无望后"restricted the work, though he did not drop it completely" |
| 失败隔离实体 | Kellex 设立（第5章） | 原班人马、独立账目与名号，明文目的"to bear the stigma of possible failure" |
| 经费倒挂 | 项目成本结构 | 约 84% 支出在铀/钚生产设施，武器实验室不足 4%——判别数据的基建才是大头 |
| 试验门/发布门分立 | Trinity vs 临时委员会（第10-11章） | "能不能用"由实验场回答；"用不用"由 1945-05 设立的另一机构、另一套席位议决 |

## 使用规则

- 引用算子说服用户时给史实锚点，不复述故事。
- 以上全部来自单一案例（曼哈顿）。跨案例验证与反例（哈勃、哥伦比亚号、北极星、
  人类基因组）在证据卡片库中已有卡片，待后续版本并入。
